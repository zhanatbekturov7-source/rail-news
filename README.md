# Лента новостей: ЖД, транзит и логистика (СНГ и Китай — Европа)

Сайт сам собирает новости каждые 3 часа и показывает их одной лентой с фильтрами по региону (схема маршрутов вверху страницы), рубрике, периоду и языку. Работает бесплатно на GitHub: сбор выполняет GitHub Actions, сайт раздаёт GitHub Pages. Сервер не нужен.

## Как запустить (10 минут, один раз)

1. Зарегистрируйтесь на github.com, если ещё нет аккаунта.
2. Создайте новый репозиторий: кнопка **New**, имя например `rail-news`, тип **Public** (для приватного репозитория Pages работает только на платном тарифе). Галочки README и прочие не ставьте.
3. На странице пустого репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** распакованной папки `rail-news` (включая скрытую папку `.github`). Нажмите **Commit changes**.
   Если папка `.github` не перетаскивается (macOS/Windows скрывают её), включите показ скрытых файлов или загрузите проект через GitHub Desktop.
4. Откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions**. Если GitHub попросит разрешение на запуск сценариев, подтвердите. Выберите слева **Обновление ленты** и нажмите **Run workflow**.
6. Через 1–3 минуты сценарий завершится, а в его результатах появится ссылка на сайт вида `https://ваш-логин.github.io/rail-news/`.

Дальше лента обновляется сама каждые 3 часа. Архив хранится 45 дней.

## Что и откуда собирается

- **Google News** по тематическим запросам на русском и английском: Средний коридор/ТМТМ, КТЖ и Казтемиртранс, Достык/Алтынколь/Хоргос, контейнерные поезда Китай — Европа, РЖД, БЖД, УТЙ, порты Актау и Курык, тарифы, логистика Центральной Азии. Это основной источник: Google сам агрегирует сотни изданий.
- **Прямые RSS** отраслевых СМИ (RailFreight.com, Гудок, РЖД-Партнёр, PortNews, Kursiv). Адреса лент сайты иногда меняют: какие источники ответили при последнем сборе, видно внизу сайта в блоке «Источники». Неработающую ленту можно поправить или удалить в `config.yaml`, на работу остальных она не влияет.

Одинаковые новости из разных изданий склеиваются в одну запись, остальные издания показываются строкой «также: …».

## Как настроить под себя

Всё настраивается в `config.yaml`, код трогать не нужно. Отредактируйте файл прямо на GitHub (иконка карандаша) и сохраните: сайт пересоберётся автоматически.

- **Добавить тему** — новая строка в `google_news`, например `'Каспийский трубопроводный OR КТК'`. Работает синтаксис поиска Google: кавычки для точной фразы, `OR`, минус-слова.
- **Добавить издание** — новый блок в `feeds` с адресом RSS-ленты.
- **Рубрики и регионы** — списки слов в `categories` и `regions`. Если меняете названия регионов, поправьте массив `STATIONS` в `site/index.html` (это станции на схеме).
- **Частота сбора** — строка `cron` в `.github/workflows/update.yml`. Время в UTC: `17 */3 * * *` — каждые 3 часа, `17 * * * *` — каждый час.

## Полезно знать

- GitHub запускает сценарии по расписанию с задержкой до 10–30 минут в часы нагрузки — это нормально.
- Если ни один источник не ответил, сценарий завершается с ошибкой, а GitHub присылает письмо. Старая лента при этом остаётся на сайте.
- Проверить сбор у себя на компьютере: `pip install -r requirements.txt`, затем `python scraper/collect.py`, затем `cd site && python -m http.server` и откройте http://localhost:8000.
