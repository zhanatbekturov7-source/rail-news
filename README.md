# КТТ Rail-News

Автоматическая лента новостей о железнодорожном транспорте, транзите и логистике в СНГ и на маршрутах Китай — Европа. Новости собираются каждые 3 часа, сайт работает бесплатно на GitHub Pages.

## Как добавить тему

1. Откройте файл `config.yaml` (на сайте внизу левой колонки есть ссылка «Добавить или изменить темы», она ведёт прямо в редактор).
2. Найдите раздел `topics:`. Скопируйте любой блок от `- name:` до следующего `- name:` и вставьте в конец списка тем, перед строкой `default_topic`.
3. Поменяйте в копии:
   - `name` — название темы, оно появится в левом меню;
   - `keywords` — слова, по которым новость относится к теме, через запятую в квадратных скобках. Пишите начало слова маленькими буквами: `угол` найдёт «уголь», «угля»;
   - `search_ru` и `search_en` — запросы, по которым собирать новости (можно не указывать: тогда тема наберётся из уже собранных новостей по ключевым словам).
4. Нажмите **Commit changes**. Через 3–5 минут тема появится на сайте, причём в неё сразу попадут и подходящие новости из архива.

Пример новой темы:

```yaml
  - name: Уголь и руда
    keywords: [угол, угл, руд, металлург, coal, iron ore]
    search_ru:
      - 'перевозки угля железная дорога'
      - 'экспорт угля Казахстан OR Россия'
```

Отступы важны: строка `- name:` начинается с двух пробелов, остальные строки блока — с четырёх, как у соседних тем.

## Где что лежит

- `config.yaml` — темы, источники, регионы. Всё содержательное меняется здесь.
- `site/index.html` — внешний вид сайта.
- `scraper/collect.py` — программа сбора новостей.
- `.github/workflows/update.yml` — расписание сбора (строка `cron`, время UTC).
- `site/data/news.json` — архив новостей, его заполняет программа сама, руками не трогать.

## Если что-то пошло не так

- На вкладке **Actions** красный крестик: нажмите на запуск, затем на блок **update**, раскройте шаг с ошибкой. Чаще всего это опечатка или сбитые отступы в `config.yaml`, тогда в логе будет слово `yaml`.
- Источник не отвечает: внизу сайта в блоке «Источники» он отмечен красной точкой. Остальные источники от этого не страдают.
